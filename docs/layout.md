# Layout

Стадия `layout` режет книгу на блоки с осью периодов и строками тела. Без fact-строк маппинг не вызывается: джоб может закончиться `succeeded` с пустым контекстом.

Код: `src/finance_context/layout/` (`detect.py`, `periods.py`) и разбор ссылок в `src/finance_context/formulas/engine.py`.

Связанные документы: [обзор](overview.md), [маппинг](mapping.md), [архитектура](architecture.md).

## Что считается блоком

На листе собираются **кандидаты осей**, затем тело от одной шапки до следующей.

Календарная шапка — строка с ≥2 ячейками, которые `classify_header` считает датой / годом / кварталом / месяцем (`2024`, `2024E`, `Q1 2025`, `01.01.2026`).

Относительная шапка (project finance) — лейбл `Year` / `Period` / `Month` / `Quarter` (и русские год/период/мес/кв) и справа непрерывный ряд целых `0|1, 2, 3, …` длиной ≥ 3. Ключи периодов: `Y1` / `Q1` / `M1` / `P1`. Роль колонки — `relative`. Grain: `model_year` / `model_quarter` / `model_month` / `model_period`. `apply_grain` календарные ключи не трогает.

Если слова Year в строке нет, но справа ≥ 8 целых `0|1..n` **и** те же колонки совпадают с самым широким formula-copy run на листе (`formula_template` / R1C1), ось всё равно строится. Счётчик `Week #` под календарём на тех же колонках второй осью не становится.

Кандидат отбрасывается, если у него меньше двух периодов (календарь) или меньше трёх (подписанная относительная ось).

## Доминирование оси

На одном листе ложные шапки часто живут **слева** от настоящего таймлайна: пара дат `Start`/`End` в допущениях при 40 колонках годов справа. Короткий календарный ряд **внутри или справа** от широкой оси тоже ложный, если набор колонок другой.

Среди кандидатов берётся самый широкий (`primary`). Остаются:

- тот же набор колонок (±1 / Jaccard ≥ 0.8) — две таблицы друг под другом на одном таймлайне;
- непересекающиеся колонки сопоставимой ширины (отношение ≥ 0.75) — две ленты side-by-side.

Кандидат, все колонки которого строго левее `min(col)` primary, или короткий чужой набор справа/внутри, отбрасывается и становится телом.

Нарезка `body_rows` идёт по **отфильтрованному** списку, не по сырым header-bands.

Formula-copy (одинаковый `formula_template` в соседних колонках, длина ≥ 3) задаёт геометрию таймлайна: шапки его подтверждают, флаги и constants без копирования по ряду осью не являются.

## Зона лейблов

Раньше `label_col = min` текстовой колонки: секции в col 2, статьи в col 4 — тело молча skip.

Сейчас для каждой строки тела берётся самая левая текстовая ячейка левее оси (не число, не период). Гистограмма таких «левых» колонок даёт `block.label_col` (argmax; при равенстве левее). `span` — эти колонки левее primary плюс primary.

Лейбл строки — первая непустая ячейка span; `indent` — позиция в span плюс ведущие пробелы. У `LayoutRow` свой `label_col` (адрес в context), если статья не в `block.label_col`.

Виды строк (`fact` / `abstract` / `index` / `helper` / `flag`) — как в [architecture.md](architecture.md). `index` только если по оси идёт `0|1, 2, 3, …` и лейбл счётчика (`week`, `#`, …) **или** в периодных ячейках нет формул. Ветка «все числа ≤ 12» снята: денежные 1..12 с формулами остаются `fact`. Плейсхолдеры `Spare` / `None` — `helper`. Сценарии (`Live Case`, `* choice`) и ряды, где по оси есть и 0, и 1, — `flag`; в маппинг они идут как excluded, значения остаются в context.

## Формулы и ось

Compile помечает формулу `unparsed`, если токен не разобран. Диапазон с квалификатором листа **на правом конце** (`SUM(TBA!$D$10:'TBA'!D10)`) допустим: префикс листа после `:` пропускается. Иначе structure не видит SUM/рёбра, а в context копятся warning.

Кэшированные значения для layout не обязательны, если текст шапки уже календарь или индекс лет.

## Что проверять, если маппинг пустой

| Симптом | Куда смотреть |
| --- | --- |
| 0 блоков | Нет календарной оси, нет `Year`+`1..n`, и нет длинного `1..n` на formula-copy колонках |
| Много блоков по 2 периода, 0 fact | Ложные Start/End не отфильтровались; или лейблы правее `label_col` |
| Блоки есть, fact = 0 | Зона лейблов / skip пустого `label_col` |
| `Unparsed formula` на шапке или SUM | `formulas/engine.py`, не таксономия |

Публичный корпус: Packt (индекс лет) и RVI (календарь + секции в нескольких колонках). Gold: `tests/fixtures/mapping/*_dispositions.yaml`. `three-statement.xlsx` в lock может быть недоступен — тест корпуса skip.

Тесты детектора: `tests/layout/`. Gold `cashflow.xlsx` не должен менять число блоков и `label_col`.
